# Golden reference provenance

Initial baseline: manually calculated from the published 0.65/0.35 formula
and policy precedence in models/MODEL_CARD.md. It covers all decisions, minimum
GPA, maximum income, and missing-document overrides of acceptance and rejection.

The nine complete outcomes are hand-authored, not generated by the tests.
The artifact fingerprint prevents silently changing the model under this baseline.
JSON object order is irrelevant; explanation text, lists, score and versions are checked.

To change: explain why in DECISIONS.md or a pull request, bump the artifact/policy
version as appropriate, manually review the old/new outcomes, and obtain a review.
Never replace this file solely to make a failing test green.
