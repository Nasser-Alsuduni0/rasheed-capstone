# Rasheed | Scholarship screening

SDA-AIE-113 capstone. A transparent, deterministic scholarship screening
service with accept, committee-review, and reject outcomes.

The policy is an illustrative course policy, not an institution's admissions
or financial-aid standard. Inputs contain no names, national IDs, or documents.
Document completeness is supplied as booleans; this service does not verify files.

Implementation and measured run instructions are added as each milestone passes.
